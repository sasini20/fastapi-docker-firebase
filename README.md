# 🚀 FastAPI, Docker & Firebase with CI/CD Pipeline

A fully automated CI/CD pipeline project demonstrating the deployment of a Python FastAPI backend integrated with Firebase, containerized using Docker. 

## 🌟 Features
* **FastAPI Backend:** High-performance RESTful API.
* **Firebase Integration:** Securely connected to Firebase using service accounts.
* **Dockerized:** Containerized for consistent environments across Development & Production.
* **Automated CI/CD:** GitHub Actions pipeline to automatically build and push Docker images to Docker Hub upon every new code commit.

## 🛠️ Technologies Used
* **Backend:** Python 3.10, FastAPI, Uvicorn
* **Database/Cloud:** Firebase Admin SDK
* **Containerization:** Docker, Docker Hub
* **Automation (CI/CD):** GitHub Actions
